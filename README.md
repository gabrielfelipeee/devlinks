## 📌 Descrição do Projeto

O **Dev Links** é uma aplicação que permite aos usuários criar um **portfólio digital personalizado** com links para redes sociais e perfis profissionais.  

✨ Com uma **interface moderna e intuitiva**, os usuários podem:  
✅ Criar um perfil digital com links personalizados;  
✅ Adicionar, editar e remover links com facilidade;  
✅ Customizar o **slug** da página para um endereço único;  
✅ Usar a interface responsiva, adaptável a todos os dispositivos.

🔗 [Repositório da API ASP.NET Core 8](https://github.com/gabrielfelipeee/Devlinks.Api)  

Para rodar a API localmente, siga as instruções do **README** da API.

## 🌍 Acesso ao Projeto

Você pode acessar a versão online do projeto clicando [aqui](https://devv-links.vercel.app).

Para rodar localmente, siga os passos abaixo:

1️⃣ Clone o repositório do front-end:
```bash
git clone https://github.com/gabrielfelipeee/devlinks.git
cd devlinks
npm install
npm run dev
```

2️⃣. O projeto depende de uma API que também precisa ser executada localmente. Para rodar a API, clone o repositório da API e siga as instruções no README da API para rodar a aplicação ASP.NET Core 8 localmente:

[Link para a API ASP.NET Core 8](https://github.com/gabrielfelipeee/Devlinks.Api)

No repositório da API, você encontrará as instruções detalhadas para rodar a aplicação localmente.
